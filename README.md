# DragShift

Утилита для macOS по мотивам вирусного ролика: **тащишь файл → зажимаешь Shift → под курсором появляется круговое меню**. Отпускаешь файл на нужный сектор, и результат сохраняется рядом с оригиналом.

| Тип файла | Действия в круге |
|---|---|
| **PDF** | DOCX · JPG · PNG · TXT |
| **Картинки** (jpg, png, heic, webp, tiff…) | Compress · Metadata · Edit · Annotate · Add BG · To PNG/JPG · Crop · Redact |
| **Документы** (docx, doc, rtf, txt, md, html, odt) | PDF · DOCX · TXT · RTF |
| **Всё остальное и папки** | ZIP · Duplicate · Copy Path |

Если навести файл на сектор, в центре круга появится название действия. Без наведения там показан размер файла. Отпустишь файл в центре — ничего не произойдёт.

### Что делает каждое действие

- **Compress**: сохраняет JPEG с качеством 72%, длинная сторона не больше 2560 px.
- **Metadata**: сохраняет копию без EXIF и GPS, ориентация фото учитывается.
- **Edit**: окно с ползунками экспозиции, яркости, контраста, насыщенности, вибрантности и резкости, плюс поворот и отражение.
- **Annotate**: рисование пером и маркером, рамки и стрелки, палитра цветов и отмена через ⌘Z.
- **Add BG**: подложка как в ролике. 9 градиентов, 9 сплошных цветов или прозрачный фон, ползунки отступа, скругления и тени, формат холста Auto, 1:1, 4:3, 16:9 или 9:16. Сохраняется в PNG.
- **Crop**: рамку можно двигать и тянуть за углы, есть пропорции Free, 1:1, 4:3, 3:4, 16:9 и 9:16, а также сетка третей.
- **Redact**: закрашивает выбранные области чёрным, пикселизирует или размывает их.
- **PDF → JPG/PNG**: каждая страница рендерится в 2× (144 dpi). Если страниц несколько, файлы получают имена `Name p1.jpg`, `Name p2.jpg`, …
- **PDF → DOCX**: переносит только текст с базовым форматированием, картинки и вёрстка не сохраняются.

Имена файлов строятся так: `Page 001.pdf` → `Page 001.jpg`, `Page 001 Cropped.jpg`, `Page 001 With BG.png`. Если имя занято, в конец добавляется номер.

## Установка

### Вариант А: готовая сборка из GitHub Actions
1. Открой вкладку **Actions** репозитория, выбери последний успешный запуск **Build** и скачай артефакт **DragShift**.
2. Распакуй архив и перенеси `DragShift.app` в `/Applications`.
3. Приложение не подписано сертификатом Apple, поэтому один раз сними карантин:
   ```bash
   xattr -dr com.apple.quarantine /Applications/DragShift.app
   ```
4. Запусти приложение. В строке меню появится иконка ◎, а в Dock иконки не будет.

### Вариант Б: собрать самому
Нужен Xcode или Command Line Tools (Swift 5.9+), macOS 13 или новее.
```bash
./build.sh                  # сборка под твою архитектуру
UNIVERSAL=1 ./build.sh      # Apple Silicon + Intel (нужен полный Xcode)
open build/DragShift.app
```

## Разрешения
- **Специальный доступ (Accessibility) не нужен.** Приложение раз в 1/30 секунды проверяет, зажата ли кнопка мыши и нужная клавиша и изменился ли drag-буфер.
- Когда ты первый раз конвертируешь файл с Рабочего стола, из Документов или Загрузок, macOS спросит разрешение на доступ к этой папке. Нажми «Разрешить».

## Настройки (иконка в строке меню)
- Включить или выключить приложение.
- Клавиша-триггер: Shift, Option, Control или Command.
- Показывать результат в Finder.
- Запуск при входе в систему.

## Структура кода
```
Sources/DragShift/
  App.swift            — меню в строке меню и настройки
  DragMonitor.swift    — определяет, что идёт перетаскивание с зажатым Shift
  RadialPanel.swift    — прозрачная панель под курсором и приём drop
  RadialMenuView.swift — отрисовка кругового меню (SwiftUI)
  Actions.swift        — какие действия доступны для какого типа файла
  Engine.swift         — конвертации PDF, текста, картинок и ZIP
  ActionRunner.swift   — запуск действий и окна редакторов
  Editors/             — Crop, Add BG, Edit, Annotate/Redact
```
