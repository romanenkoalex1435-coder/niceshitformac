# DragShift

Утилита для macOS по мотивам вирусного ролика: **тащишь файл → зажимаешь Shift → под курсором появляется круговое меню**. Отпускаешь файл на нужный сектор, и результат сохраняется рядом с оригиналом.

Во время перетаскивания **нажми Shift ещё раз**, чтобы перелистнуть круг на следующую страницу (в центре круга подписано, какая будет следующей).

| Тип файла | Страницы круга |
|---|---|
| **Картинки** | **Tools:** Compress · Metadata · Edit · Annotate · Add BG · Remove BG · Crop · Redact → **Convert:** PNG · JPG · HEIC · WEBP · TIFF · AVIF · PDF · Text |
| **PDF** | **Convert:** DOCX · JPG · PNG · TXT → **PDF Tools:** Compress · Split / Merge · Rotate · Lock · Text |
| **Документы** (docx, doc, rtf, txt, md, html, odt) | PDF · DOCX · TXT · RTF · Text |
| **Видео** (mov, mp4, m4v) | MP4 · 720p · GIF · Audio |
| **Любой файл** (последняя страница) | **Share:** AirDrop · Path · ZIP · Duplicate |

### Дизайн
- **Liquid Glass.** На macOS 26 секторы, центральная линза, тост и окна редакторов сделаны из системного стекла (`glassEffect`, `NSGlassEffectView`). На macOS 13–15 вместо него рисуется имитация стекла: размытие рабочего стола, блик и светлая кромка.
- **Секторы.** Каждый сектор — отдельная скруглённая «подушка» с ровными зазорами. Сектор под курсором выдвигается наружу и светится оранжевым, а на трекпаде слегка вибрирует (haptic).
- **Тост.** После действия внизу экрана появляется стеклянная плашка с превью результата. Клик по ней открывает файл в Finder.

### Что делает каждое действие
- **Compress**: сохраняет JPEG с качеством 72%, длинная сторона не больше 2560 px. Для PDF картинки внутри пережимаются в JPEG, текст остаётся текстом.
- **Metadata**: сохраняет копию без EXIF и GPS.
- **Remove BG** (macOS 14+): вырезает объект и сохраняет PNG с прозрачным фоном, как «Скопировать объект» в Фото.
- **Text**: распознаёт текст на картинке или в скане PDF, понимает русский и английский. Результат сразу копируется в буфер обмена.
- **Edit**: окно с ползунками экспозиции, яркости, контраста, насыщенности, вибрантности и резкости, плюс поворот и отражение.
- **Annotate**: рисование пером и маркером, рамки и стрелки, палитра цветов и отмена через ⌘Z.
- **Add BG**: 9 градиентов, размытая копия самой фотографии, 8 сплошных цветов, прозрачный фон или своя картинка. Ползунки отступа, скругления и тени показывают значения в px, есть формат холста Auto, 1:1, 4:3, 16:9 или 9:16.
- **Crop**: рамку можно двигать и тянуть за углы, есть пропорции и сетка третей.
- **Redact**: закрашивает выбранные области чёрным, пикселизирует или размывает их.
- **PDF**: если перетащить несколько картинок, получится один PDF. Если перетащить несколько PDF, вместо Split появится Merge.
- **Lock**: запрашивает пароль и сохраняет защищённую копию PDF.
- **GIF**: берёт первые 15 секунд видео, 12 кадров в секунду, до 540 px.
- **Audio**: сохраняет звуковую дорожку видео в M4A.
- **PDF → DOCX**: переносит только текст с базовым форматированием.

Имена файлов строятся так: `Page 001.pdf` → `Page 001.jpg`, `Page 001 Cropped.jpg`, `Page 001 No BG.png`. Если имя занято, в конец добавляется номер.

## Установка

### Вариант А: готовая сборка из GitHub Actions
1. Открой вкладку **Actions** репозитория, выбери последний успешный запуск **Build** и скачай артефакт **DragShift**.
2. Распакуй архив и перенеси `DragShift.app` в `/Applications`.
3. Приложение не подписано сертификатом Apple, поэтому один раз сними карантин:
   ```bash
   xattr -dr com.apple.quarantine /Applications/DragShift.app
   ```
4. Запусти приложение. В строке меню появится иконка ◎, а в Dock иконки не будет.

### Вариант Б: собрать самому
Нужен Xcode или Command Line Tools (Swift 5.9+), macOS 13 или новее.
```bash
./build.sh                  # сборка под твою архитектуру
UNIVERSAL=1 ./build.sh      # Apple Silicon + Intel (нужен полный Xcode)
open build/DragShift.app
```

## Разрешения
- **Специальный доступ (Accessibility) не нужен.** Приложение раз в 1/30 секунды проверяет, зажата ли кнопка мыши и нужная клавиша и изменился ли drag-буфер.
- Когда ты первый раз конвертируешь файл с Рабочего стола, из Документов или Загрузок, macOS спросит разрешение на доступ к этой папке. Нажми «Разрешить».

## Настройки (иконка в строке меню)
- Включить или выключить приложение.
- Клавиша-триггер: Shift, Option, Control или Command.
- Показывать результат в Finder.
- Запуск при входе в систему.

## Структура кода
```
Sources/DragShift/
  App.swift            — меню в строке меню и настройки
  DragMonitor.swift    — определяет, что идёт перетаскивание с зажатым Shift
  RadialPanel.swift    — прозрачная панель под курсором и приём drop
  RadialMenuView.swift — отрисовка кругового меню (SwiftUI)
  Actions.swift        — какие действия доступны для какого типа файла
  Engine.swift         — конвертации PDF, текста, картинок и ZIP
  MediaTools.swift     — инструменты PDF, распознавание текста, Remove BG, видео
  Glass.swift          — Liquid Glass и запасной вариант стекла
  HUD.swift            — стеклянный тост с результатом
  ActionRunner.swift   — запуск действий и окна редакторов
  Editors/             — Crop, Add BG, Edit, Annotate/Redact
```
